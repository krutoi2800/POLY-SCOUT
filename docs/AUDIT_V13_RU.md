# POLY SCOUT v13 — отчёт повторной проверки

Дата проверки: 23 ноября 2026.

## Что проверено

- Главная страница: HTML-структура, локальные ссылки/пути, загрузка JS, поиск, фильтры, карточки, ручное добавление компании, защита от дублей, статусы, приоритет, заметки, избранное, CSV, JSON-копия CRM и кнопка обновления.
- Ферма: загрузка Canvas, отображение инвентаря, фильтры категорий, выбор семян, приготовление еды, употребление еды, изменение энергии и запись состояния в сохранение.
- Аркада: загрузка Canvas, 10 селекторов боссов, 10 платформенных уровней, запуск уровня, пауза, клавиатурные и указательные события.
- Адаптивность трёх страниц на ширинах 320, 375, 390, 768, 1024 и 1440 CSS-пикселей.
- Синтаксис всех JavaScript-файлов через `node --check`.
- Пять автоматических unit-тестов сборщика данных через `python -m unittest discover -s tools -p 'test_*.py'`.
- Существование всех локальных путей к CSS, JS и страницам, на которые ссылается HTML.
- Валидность стартового `data/leads.json`.

## Что было найдено и исправлено

1. Скрытая кнопка «Показать ещё» могла иметь отрицательный остаток в тексте, если в списке меньше 80 компаний. Теперь при отсутствии дополнительных результатов её текст нейтральный.
2. Если Overpass не отвечал, workflow мог завершиться до публикации сайта. Теперь он сохраняет последнюю корректную базу и всё равно продолжает публикацию; ошибка сбора остаётся видна в логах Actions.
3. Из предыдущего архива удалены временные `__pycache__` / `.pyc`. Добавлены `.gitignore` и `.nojekyll`; в `.gitignore` включены локальные JSON-копии CRM и фермы.

## Результаты

- `node --check`: все JS-файлы прошли.
- Python unit-тесты: 5 из 5 прошли.
- Локальные ссылки и пути HTML: пропусков не найдено.

- CRM: добавление компании, дубль-блокировка, изменение статуса/приоритета/заметки, избранное, CSV и резервная копия проверены.

- Аркада: 10 боссов выбираются, 10 уровней отображаются, запуск/пауза и ввод проверены.

## Ограничения проверки

Тестовая среда блокирует прямую навигацию Chromium к локальным и сетевым URL (`ERR_BLOCKED_BY_ADMINISTRATOR`). Поэтому страницы тестировались в Chromium путём загрузки фактических HTML/CSS/JS в тестовый документ с имитацией `localStorage` и ответа базы. Это проверяет логику и вёрстку исходников, но не заменяет запуск ZIP двойным щелчком на Windows или публикацию на реальном GitHub Pages.

Не проверялись: реальный запуск GitHub Actions в аккаунте пользователя, живой запрос к Overpass, многодневное прохождение игр, все случайные сочетания игровых событий и сохранение между разными устройствами/браузерами. Абсолютное отсутствие всех возможных багов гарантировать нельзя.

## Важное о стартовой базе

`data/leads.json` в архиве содержит пустой массив `leads`. При первом открытии отображаются 8 стартовых карточек из `data/seed.js`, помеченных как `sample`; их контакты и актуальность нужно перепроверить. Первый push в GitHub только публикует сайт. После публикации запустите сбор вручную из вкладки Actions. Далее расписание пытается проверять по 3 города за запуск; полный цикл списка из 45 городов занимает около 15 запусков.
